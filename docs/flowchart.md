# 视觉抓取完整流程图

本文只画流程，不替代完整技术说明。具体参数和注意事项以
`docs/grasp.md` 为准。

项目后续还会增加盒子双手搬运阶段，设计边界见 `docs/transport.md`。
当前已经跑通：塑料袋抓取闭环、货架箱子 AprilTag 放置流程。

## 运行入口

- 机器人端：在 `huimin1.4` 容器启动 rosbridge，端口 `9091`。
- 电脑端：在 `detect` conda 环境执行完整流程。
- 当前完整流程命令：

```bash
python apps/grasp/run_grasp_flow.py \
  --ws-url ws://192.168.20.102:9091 \
  --return-mode qr-present \
  --scan-qr-after-present \
  --qr-transport raw \
  --qr-raw-throttle-ms 3000 \
  --place-after-qr \
  --max-z 1.70 \
  --execute
```

## 压力失败恢复

- 适用位置：
  - 抓取点压力检查失败。
  - QR 展示点压力检查失败。
  - OCR/QR 识别后压力检查失败。
- 固定策略：
  - 不补夹。
  - 不改手掌参数。
  - 回 `via1`。
  - 打开手掌。
  - 重新低头锁存。
  - 最多重试一次。

```text
┌──────────────────────────┐
│ 任一压力检查失败          │
└────────────┬─────────────┘
             ↓
┌──────────────────────────┐
│ 回到 via1                 │
│ 抓取点: 抓取点 -> via3 -> via2 -> via1 │
│ QR点: QR -> via3 -> via2 -> via1 │

             ↓
┌──────────────────────────┐
│ 手掌打开                  │

┌──────────────────────────┐
│ 是否还有重试次数？         │
└───────┬───────────┬──────┘
```

## 当前关键参数

- 手眼矩阵：
  - `data/calibration/cam2head_vendor_new_20260803.json`
- 视觉抓取点：
  - `bbox_x = 0.50`
  - `bbox_y = 0.333`
- 默认 TCP offset（`tuned_with_orientation`）：
  - `offset_x = 0.045`
  - `offset_y = -0.095`
  - `offset_z = 0.35`
- 回退版 TCP offset（`legacy_no_orientation`）：
  - `offset_x = -0.04`
  - `offset_y = -0.10`
  - `offset_z = 0.35`
  - `above_object_height = 0.02`
- 手掌打开：
  - `[-0.1, 0.05, 0.35, 0.35, 0.35, 0.35]`
- 手掌闭合：
  - `[0.5, 0.8, 0.84, 0.84, 0.35, 0.35]`
- 压力阈值：
  - 抓取点：`max_pressure >= 0.00`
  - QR 展示点：`max_pressure >= 0.00`
  - QR 扫码后：`max_pressure >= 0.00`
